Goni Sword Skill + Visible Sword Guard 3.3.0

이번 버전의 검 기능은 3.2의 동시 입력 연계를 대체하는 별도 기술입니다.
검 이외 무기의 Mouse5 평캔은 기존 3.1 입력 흐름을 사용합니다.

설치
1. 게임을 종료합니다.
2. 기존 Goni.DaggerPerfectCancel.dll을 별도 폴더에 백업합니다.
3. BepInEx/plugins 안의 기존 파일을 이 ZIP의 Goni.DaggerPerfectCancel.dll로 교체합니다.
   같은 DLL의 다른 버전을 plugins 하위 폴더에 중복으로 두지 마세요.
4. 게임을 실행합니다. 기존 설정 파일을 삭제할 필요는 없습니다.
   새 설정은 BepInEx/config/goni.valheim.daggerperfectcancel.cfg에 추가됩니다.
   구버전 [Sword] Enabled / DualHoldTimeoutSeconds는 새 검 기술에서 사용하지 않습니다.

조작
- 검을 들고 Mouse5(XBUTTON2)를 한 번 누르면:
  평타 1회 -> 실제 막기 자세 -> 보조공격 피해 계수의 검 1·2·3타 -> 종료.
- 막기 이후에 준비용 평타가 추가로 들어가지 않습니다.
- 세 참격은 검의 기본 1·2·3타 모션입니다. 보조공격 찌르기 모션을 세 번 반복하는 방식이 아닙니다.
- 세 참격 각각은 해당 검 보조공격의 피해 배율, 체력에 따른 피해 보정, 경직/넉백 배율을 사용합니다.
  원래 평타 3타의 마지막 타격 추가 배율은 중복 적용하지 않습니다.
  적 방어력·저항·숙련도·상태 효과·피해 난수·다른 전투 모드에 따른 최종 피해 차이는 남습니다.
- 세 참격의 공격 스태미나 비용은 0입니다. 첫 평타, 실제 피격 방어, 달리기 비용은 원래대로입니다.
- 실제 공격 애니메이션 이벤트와 연계 가능 시점을 확인하므로, 적 명중과 허공의 시간 차이를 고정 Sleep으로 맞추지 않습니다.
- Mouse5를 누른 채 있어도 반복하지 않습니다. 손을 뗐다가 다시 누르면 다음 기술을 실행합니다.
- F12: 진행 중 기술/평캔 중단, 주입 입력 해제, 검막 2초 억제.
- 회피/점프, 사망, 경직, 장비 변경, UI 열기, 창 전환 시 기술을 중단합니다.

검막
- 기본 ON, F9로 켜기/끄기. 화면 중앙에 ON/OFF 메시지를 표시합니다.
- 검 한 자루로, 정면 가까운 적의 근접 공격을 감지하면 실제 막기 입력을 유지합니다.
- 왼손에 방패/횃불 등을 들면 검막은 작동하지 않습니다. 검 자체의 방어 모션을 쓰기 위한 조건입니다.
- 게임의 원래 막기 자세와 막기 충돌/패링 애니메이션, 방어력, 스태미나 규칙을 사용합니다.
- 패링은 원래 게임의 유효 시간 안에 맞았을 때 성립합니다. 모든 공격을 자동 패링하는 기능은 아닙니다.
- 수동 공격/회피와 삼연참 진행이 우선입니다. 공격 중 피해를 투명하게 지우거나 무적으로 만들지 않습니다.
- 뒤쪽 공격, 원거리 투사체, 환경 피해, 막을 수 없는 공격까지 보장하지 않습니다.
- 적 감지는 초당 최대 20회, 할당 없는 목록 순회입니다. 개별 적을 장기간 저장하거나 로그를 계속 쌓지 않습니다.

주요 설정
[SwordSkill]
Enabled = true
VisibleBlockSeconds = 0.18
StageTimeoutSeconds = 8

[SwordGuard]
Enabled = true
MeleeWatchRange = 6
HoldAfterThreatSeconds = 0.25

[Debug]
VerboseLogging = true
원인 확인 후 false로 바꾸면 세부 전환/타격 로그를 줄일 수 있습니다.

검증 및 확인할 로그
- Windows Release 빌드 및 상태 전환/입력 회귀 테스트를 수행합니다.
- 이 환경에서는 Valheim 클라이언트를 실행할 수 없어 화면 모션, 실제 피해 수치와 다른 모드 호환성은 실게임 검증 전입니다.
- 시작 시 [SwordSkill] Ready 메시지 및 버전 3.3.0을 확인합니다.
- 성공한 연계는 [SwordSkill #N] ... complete: opening=1, slashes=3 으로 끝납니다.
- 막기 단계는 Animator에서 'block' 이름을 포함한 실제 재생 클립을 두 프레임 이상 관측하고,
  VisibleBlockSeconds 이상 유지한 경우에만 통과합니다.
- 모션을 찾을 수 없으면 watchdog at Block으로 중단합니다. 진단을 위해 현재 모션 이름을 로그에 남깁니다.
- 다른 무기/게임 패치/애니메이션 교체 모드로 검 3단 모션이나 API가 달라지면 경고 후 실행을 거절할 수 있습니다.

구현 범위
- 새 Attack 객체를 직접 생성해서 피해를 바로 넣지 않습니다. 게임의 Humanoid.StartAttack이 만든 해당 기술용 복제본만 설정합니다.
- 무기 공용 데이터, 다른 플레이어, 일반 수동 평타/보조공격의 피해·스태미나는 변경하지 않습니다.
- DoMeleeAttack의 실제 이벤트를 타격당 한 번 처리하며 중복 이벤트는 억제합니다.
- 검막은 IsBlocking, RPC_Damage, BlockAttack을 패치하지 않으며 체력이나 패링 타이머를 수정하지 않습니다.
- 기존 Foresight 파일은 이 패키지에 포함하지 않습니다.
